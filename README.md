# Bulrang Website Redesign

A Figma-based website redesign project for **Bulrang**, created as part of an internship task focused on improving the usability, structure, and presentation of the website.

## Project Overview

This project presents a redesign concept for the Bulrang website. The goal was to fix key usability and layout issues in the existing design and create a clearer, more user-friendly experience.

The redesign includes the following main pages:
- Home Page
- Services Page
- Service 1 Page
- About Us Page

## Objective

The purpose of this project was to improve the overall user experience of the website by making the content easier to navigate, the services easier to understand, and the interface more visually consistent.

## Problem

The existing website design had issues with:
- unclear navigation
- weak content hierarchy
- lack of consistency between pages

These problems could make it difficult for users to quickly understand the brand and find the information they need.

## Solution

The redesign solves these issues by:
- creating a clearer page structure
- improving navigation between key sections
- highlighting services with dedicated layouts
- using a more consistent and modern visual style
- making the website easier to scan and understand

## Pages Included

### Home Page
The home page introduces Bulrang and provides users with a clear entry point into the website. It is designed to quickly communicate the brand and guide visitors to important sections.

### Services Page
The services page organizes the company’s offerings in a more structured way, making it easier for users to browse and compare available services.

### About Us Page
The about page helps build trust by presenting information about the company, its background, and its identity in a clean and accessible format.

## Tools Used

- Figma

## Outcome

The final result is a cleaner and more structured website design that improves usability and better presents Bulrang’s content and services.

Possible next steps for the project include:
